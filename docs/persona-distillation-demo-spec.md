# 人物画像蒸馏 Demo 预期定义

## 1. 目标

把论坛作者从“消息列表里的发言者”升级成“可被系统持续理解的人物对象”。
这个 demo 不以聊天为中心，而以画像、证据、变化和联动为中心。

## 2. Demo 要回答的问题

1. 这个人长期是什么风格。
2. 这个人最近在关注什么。
3. 这个人的立场有没有漂移。
4. 他的判断依据能不能追溯回原文。
5. 这个画像能不能被别的模块复用。

## 3. 输入

画像对象的最小输入应包括：

- 作者名或 UID
- 历史帖子消息
- 时间戳
- 原文内容
- 结构化提及信息
- 关联股票/板块/指数信息
- 近期增量消息

## 4. 输出

画像的标准输出应包含：

- `summaryText`
- `axes`
  - 立场
  - 表达风格
  - 时间尺度
  - 风险偏好
  - 题材偏好
- `evidence`
  - 支撑结论的原句
  - 原帖楼层
  - 时间戳
  - 相似轴
- `recentChange`
  - 近期是否漂移
  - 漂移方向
  - 变化依据
- `relatedTopics`
  - 最近高频提及股票
  - 题材
  - 板块
- `confidence`
  - 画像置信度
  - 证据覆盖度
- `freshness`
  - 最近更新时间
  - 覆盖消息数
  - 覆盖 chunk 数

## 5. 预期结果长什么样

一个合格的画像结果，不是长篇聊天，而是能直接扫描的结构化结论。

示例：

- 总结：该作者整体偏谨慎，擅长结合盘口和题材节奏做短线判断。
- 立场：偏中性到谨慎，不轻易追高。
- 风格：偏复盘、偏策略表达，喜欢给出明确条件。
- 时间尺度：短线到波段。
- 风险偏好：中性偏保守，强调控制回撤。
- 题材偏好：科技、机器人、半导体、板块轮动。
- 证据：来自最近若干条原帖原句，可点击回查。

## 6. Demo 页面定义

Demo 页面建议是“作者画像页”，不是聊天页。

页面结构：

1. 顶部信息区
   - 作者名
   - UID
   - 最近更新时间
   - 覆盖消息数
   - 画像置信度
2. 中间画像区
   - 五维画像卡
   - 最近变化提示
   - 高频题材
3. 证据区
   - 按时间倒序展示原文
   - 每条证据标注对应轴
   - 点击可跳回原帖
4. 联动区
   - 最近提到的股票
   - 相关板块走势
   - 相关消息摘要

## 7. 复用方式

这层画像应当被下面模块共享：

- Agent 问答
- 消息流高亮
- 实时监控
- 日报/周报
- 股票联动分析

## 8. 验收标准

1. 输入一个作者，能生成稳定画像。
2. 画像能展示证据，不是只有结论。
3. 新消息进入后，画像可增量更新。
4. 画像可以被 Agent 和看板同时读取。
5. 页面上能看出“这个人是谁、怎么想、依据是什么”。
